# Forward Forward

Absolutely. Below is a comprehensive Lovable.dev master prompt designed to create a premium church website for Forward Church Ministries. It combines the cinematic hero experience inspired by Sanctuary with the clean, content-rich layout inspired by Motivation Church, while making the branding completely unique to Forward Church Ministries.

Forward Church Ministries Website Master Prompt for Lovable.dev

Project Overview

Build a modern, premium church website for Forward Church Ministries located in Mobile, Alabama.

The website should feel welcoming, contemporary, inspiring, and community-focused while remaining simple to navigate for first-time visitors, members, and volunteers.

Do not copy another church website. Instead, create a unique experience inspired by:

The immersive full-screen hero section, transparent navigation, and cinematic presentation of Sanctuary Church.

The clean page organization, modular layout, visitor journey, and spacing of Motivation Church.

The final product should feel like a church website designed by a professional creative agency in 2026.
